# Basic Calculator

A simple, functional calculator built using **HTML, CSS, and Vanilla JavaScript**.

This was one of my first complete JavaScript projects, built to practice DOM manipulation, event handling, and implementing logic independently.

## Live Demo

[Try the Calculator](https://saadvikbutti.github.io/basiccalc/)

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication and Division
- Modulo operation
- Decimal number handling
- Positive and negative number toggling
- AC (All Clear) functionality
- Delete functionality
- Chained calculations
- Continue calculations after pressing Equals
- Handles basic calculation edge cases

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Highlights

- Implemented the calculation logic independently without using JavaScript's `eval()` function.
- Used DOM manipulation to handle user interactions and update the calculator display.
- Practiced JavaScript functions, conditional statements, and event handling.

## What I Learned

- Working with DOM elements
- Handling click events
- Managing calculator state
- Implementing arithmetic operations using JavaScript
- Handling decimal and negative numbers
- Structuring and debugging JavaScript logic

## Running Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
